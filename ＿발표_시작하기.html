발표 진행 방법

  1. 발표는 메인 슬라이드 덱(HTML)으로 진행하세요. 더블클릭해 브라우저에서 열고 F11로 전체화면.
  2. 이동은 →/스페이스(다음), ←(이전), Home/End(처음/끝). 우측 하단 화살표 버튼·스와이프도 됩니다.
  3. PDF가 필요하면 어떤 HTML이든 Ctrl+P → 대상을 ‘PDF로 저장’. (덱은 슬라이드별 1페이지로 저장됩니다)
  4. 회사에서 PPT가 표준이면 PPTX를 쓰세요. 내용은 HTML 덱과 동일합니다.

발표 전 딱 1가지만 수정

  • 표지의 “발표자 ____________” 부분에 이름을 넣으세요.
    → HTML은 편집기로 발표자 검색 후 수정 / PPTX는 1번 슬라이드에서 직접 입력.
  • (선택) 발표 대본 ‘발표 팁 ⑤’처럼 실제 수치(예: 캠페인당 문자 횟수, 월 인원 수)를 넣으면 설득력이 크게 올라갑니다.

구성 (34슬라이드 · 6파트)

  • Part 1 배경 (1–3) — 규모는 커졌는데 방식은 그대로
  • Part 2 현황 진단 (4–9) — 모집·연락·배송·정산·검수 5단계 문제
  • Part 3 솔루션 개요 (10–12) — 두 앱 + AI, 전체 구조, 문제→해결 매핑
  • Part 4 단계별 해결 & 화면 (13–18) — 실제 화면 목업 + AI 자동화
  • Part 5 운영 실행 (19–30) — 개요 / 대량 연락·단계별 시나리오 / 인바운드 모집(허브·노출·레퍼럴) / 인스타 콘텐츠(포트폴리오·트렌드·교육·모집·자동화)
  • Part 6 효율·기술·로드맵 (31–34) — Before/After, 기술·보안, 다음 단계

참고

  • 슬라이드 안의 앱 화면은 실제 코드 기반의 고품질 목업입니다. 더 생생하게 하려면 발표 중 실제 어드민·인플루언서 앱을 라이브로 띄워 보여주면 효과가 큽니다(13·16·17번 추천).
  • 이 발표는 우리의 현황진단 5단계 문제와, 실제로 만든 어드민·인플루언서 앱의 기능을 1:1로 매핑해 구성했습니다.
  • build_pptx.py는 PPTX 생성 스크립트입니다(재생성·수정용, 발표엔 불필요).
