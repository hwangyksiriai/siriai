02 — 1 모집 단계

Pool 고갈과 감도 하락

모집
✕
아웃바운드(DM)에만 의존 — 인스타 뷰티 태그 검색 + DM. “보내던 사람에게만 또 보내는” 모수 고갈.
✕
장기 클라이언트 만족도 저하 — 풀이 1년간 순환되지 않아, 무신사 등에서 “감도 높은 인원 재구성” 불만 누적.
✕
크리에이터 성향 자산화 부재 — 누가 색조에 강한지, 스킨케어 릴스를 잘 만드는지 분류가 없어 매번 기억에 의존한 수기 매칭.
✕
1:1 개별 제안의 리소스 낭비 — 캠페인마다 적합해 보이는 사람에게 일일이 연락해 선호·고료를 개별 확인.

→ 신규 캠페인이 생길 때마다 태그 검색과 수기 1:1 컨택을 처음부터 반복하는 비효율이 고착화.

02 — 2 연락 단계

수작업 커뮤니케이션으로 인한 과부하

연락
✕
공식 채널 부재 · 개인 폰 사용 — 회사 공식 채널이 없어 담당자 개인 휴대폰에 번호를 일일이 저장해 소통.
✕
다단계 1:1 연락으로 마비 — 캠페인당 [피처체크 → 선정안내 → 가이드 배송 → 리마인더 3회]를 전부 수동 문자.
✕
라포 ↔ 효율의 충돌 — 친절한 1:1 응대·고료 협의를 유지하고 싶지만 단체 시스템이 없어 효율 급락. (오픈채팅은 감도와 안 맞음)
✕
정보 공개의 딜레마 — 공공 채널에 올리면 고료(평균 5만 원)가 투명 노출 → 고단가 A급의 참여가 제한됨.

→ 클라이언트 수가 몇 배로 늘어난 지금, 담당자 혼자 감당 불가능한 임계점에 도달.

02 — 3 선정 후 배송 단계

데이터 최신화 부재로 인한 배송 사고

배송
🚫 문제 A
✕
과거 데이터 재활용 — 이전에 참여한 인플루언서의 주소를 확인 없이 그대로 브랜드사에 전달.
✕
이사 등으로 오배송이 주기적으로 발생 → 브랜드 신뢰 손상.
🚫 문제 B
✕
이를 막으려고 한 명 한 명 주소를 수동 재확인하는 전수조사식 프로세스가 추가됨.
✕
결국 사고를 막으려다 공수가 또 늘어나는 악순환.

→ “최신 데이터를 자동으로 받을 방법”이 없어, 틀리거나 / 매번 다시 묻거나 둘 중 하나였습니다.

02 — 4 정산 단계

중복 공수 & 패널티 통제 불능

정산
✕
중복 서류 제출 피로 — 여러 번 참여해도 매 캠페인마다 신분증·통장사본을 메일로 새로 수취.
✕
수기 송금의 비효율 — 담당자가 메일로 취합 → 슬랙 공유 → 대표가 하나하나 수기 송금·체크. 인원↑ 시 누락·지연 위험.
✕
낮은 고료로 잠수(노쇼) — “5만 원 안 받고 말지”로 기한 미준수·연락 두절이 다수.
✕
패널티 기준 부재 — 늦게 올려도 대부분 정산 → 책임감 결여. 미업로드 인원 설득에 감정 소모.

→ 정산이 ‘돈 주는 일’이 아니라 ‘사람 쫓아다니는 일’이 되어 있었습니다.

단순 반복 수작업으로 인한 과부하

→ 가장 단순한 일에 가장 많은 손이 들어가, 정작 ‘콘텐츠 품질을 보는 일’엔 시간을 못 썼습니다.

06 운영 실행 · 개요

앱을 만든 게 끝이 아닙니다 — 이렇게 운영하고 키웁니다.

회사에서 가장 궁금해할 부분 — 시스템을 실제로 어떻게 굴리고, 신규 인플루언서를 어떻게 모으고, 채널을 어떻게 키울지를 3개 축으로 정리했습니다.

축 1

대량 연락

개인 폰 대신 문자 API·카카오 알림톡으로, 앱 DB와 연동해 단계별 자동·일괄 발송.

축 2

인바운드 모집

인스타 허브 + 레퍼럴 + 기존 DB로 ‘찾아오게’ 만드는 신규 유입 엔진.

축 3

인스타 채널

저장하고 싶은 콘텐츠로 브랜딩 → 앱 유입·락인 → 다시 모집으로 순환.

운영 원칙 3

① 단순 반복은 자동화

문자·검수·정산·콘텐츠 초안은 시스템·AI가. 사람은 판단·관계에 집중.

② 아웃바운드 → 인바운드

찾아 나서는 모집을, 찾아오는 구조로 전환.

③ 한 번 만들어 여러 번

결과물·콘텐츠를 재활용(아카이브·크로스미디어)해 적은 손으로 운영.

06 운영 실행 · 대량 연락

개인 폰 없이, 수백 명에게 한 번에.

인플루언서 앱 DB(상태·단계)와 연동해 맞춤 대량 발송. 선정·리마인드·정산 안내를 단계에 맞춰 버튼 한 번으로.

📨

방법 1 · 단체 문자 발송 API

  • ·
    알리고 · 문자나라 · 솔라피 등 문자 API 연동
  • ·
    한 번에 수십~수백 명, 이름·캠페인 자동 치환 맞춤 문자
  • ·
    비용 월 몇만 원 수준
💬

방법 2 · 카카오 알림톡

  • ·
    카카오 비즈니스 채널 개설 후 발송
  • ·
    카톡 형식이라 친숙 · 개인 번호 노출 없이 대량
  • ·
    읽힘률이 일반 문자보다 높음

현재 앱 내 알림 → 문자·알림톡으로 휴대폰까지 도달 강화. 둘 다 앱과 연동해 단체 발송이 핵심.

06 운영 실행 · 단계별 자동 발송

캠페인 한 건의 연락, 이렇게 자동화됩니다.

예전엔 캠페인당 [피처체크 → 선정 → 가이드 → 리마인더 3회 → 정산]을 전부 손으로 문자. 이제는 앱 상태에 맞춰 템플릿 + 버튼 한 번으로.

단계발송 내용채널자동화 포인트
① 섭외·모집 안내캠페인 오픈 · 신청 유도알림톡 · 문자DB 필터 대상에 일괄
② 선정 안내“선정되셨어요” + 일정앱 알림 + 알림톡‘진행’ 선정 시 자동 트리거
③ 가이드 전달촬영·업로드 가이드 링크앱 + 알림톡캠페인 가이드 자동 첨부
④ 리마인드 ×33일 전 · 1일 전 · 당일알림톡 · 문자업로드 마감 기준 예약
⑤ 정산 안내지급 예정 · 완료 통지앱 + 알림톡지급완료 처리 시 자동

→ AI influencer-dm 스킬이 각 단계 메시지 초안을 톤 맞춰 작성, 담당자는 확인·발송만.

06 운영 실행 · 인바운드 모집 · 개요

찾아 나서지 않고, 찾아오게 만든다.

🏢

인스타 = 인바운드 허브

“감도 높은 뷰티·패션 브랜드 × 크리에이터” 포지셔닝. 프로필에 앱 링크(링크바이오).

📲

상시 노출

진행 결과물(공동작업자 릴스·피드) 자연 노출 + 스토리에 ‘모집중 캠페인’ 정기 업로드.

🤝

레퍼럴(지인 추천)

기존 인플루언서에게 ‘비슷한 감도 지인’ 추천 요청. 진행 성사 시 소개 리워드.

🔔

기존 DB 활성화

기존 협업 인플루언서에게 메일·문자·알림톡으로 앱 가입 유도.

성장 플라이휠

① 인스타 노출·결과물→ ② 앱 가입·캠페인 신청→ ③ 캠페인 진행→ ④ 고퀄 결과물 확보↻ 다시 콘텐츠 + 레퍼럴

→ 광고비에 기대지 않고, 결과물이 다음 모집을 부르는 선순환으로 검증된 신규 풀을 늘립니다.

06 운영 실행 · 모집 ① 인스타 허브

회사 인스타그램 = 인바운드의 중심.

  • ＋
    포지셔닝 — “감도 높은 뷰티·패션 브랜드와 크리에이터를 잇는다”를 한 줄로 각인.
  • ＋
    프로필 = 전환 장치 — 소개문 + 링크바이오에 인플루언서 앱 링크(가입·모집중 캠페인) 고정.
  • ＋
    운영 목표 — 팔로워(=잠재 인플루언서 풀)를 모으고 자연스럽게 앱으로 유입.
  • ＋
    두 대상 동시 공략 — 인플루언서에겐 “여기서 협업하고 싶다”, 브랜드엔 “대행 맡기고 싶다”.

프로필 예시

SIRIAI · 뷰티·패션 인플루언서 마케팅
─ 감도 높은 브랜드 × 크리에이터 매칭
─ 진행 캠페인 포트폴리오 큐레이션
─ 지금 모집중 캠페인 신청 👇
🔗 link.in/siriai-app

핵심 — 인스타는 ‘광고판’이 아니라 앱으로 가는 입구. 모든 콘텐츠 끝에 “앱에서 신청·확인” 동선을 둔다.

06 운영 실행 · 모집 ② 노출 전략

결과물 자체가 광고가 되게 한다.

🤝

공동작업자(협업) 노출

진행 인플루언서 게시물에 회사 계정을 공동작업자로 → 그들의 피드에 우리 계정이 함께 노출. 그 게시물로 광고 집행까지 가능.

🎞️

결과물 재업로드

진행한 릴스·피드를 인플루언서 태그 포함해 회사 계정에 재업로드 → 포트폴리오 + 자연 도달.

📲

스토리 상시 모집

“현재 모집중 캠페인” 스토리를 정기 업로드 → 팔로우 중인 기존 인플루언서가 보고 바로 신청.

→ 별도 제작물 없이 이미 가진 캠페인 결과물로 노출을 만들고, 그 노출이 다시 신청으로 이어집니다.

06 운영 실행 · 모집 ③ 레퍼럴 · 기존 DB

검증된 사람이, 검증된 사람을 데려온다.

🤝 레퍼럴 (지인 추천)
✓
진행 이력 있는 인플루언서에게 “비슷한 감도의 지인 추천” 요청.
✓
소개 인센티브 — 추천한 지인이 가입·승인 + 실제 캠페인 진행 시 소정의 리워드.
✓
‘성과 연동’이라 비용 효율적 + 감도 검증된 풀이 들어옴.
🔔 기존 DB 활성화
✓
그동안 협업한 인플루언서 전체에게 앱 가입 안내 발송(메일·문자·카톡).
✓
“이제 신청·정산·소통이 앱 한 곳에서” 가치를 전달.
✓
잠들어 있던 풀을 활성 사용자로 전환.

→ 광고 의존 없이 신뢰 기반으로 풀을 늘리고, 자발적 추천 시스템으로 지속 유입.

06 운영 실행 · 인스타 채널 · 개요

팔리는 광고가 아니라, ‘저장하고 싶은 채널’.

콘텐츠 4기둥

포트폴리오

크리에이터 아카이브 — 진행 결과물 큐레이션. “여기서 하면 퀄리티 브랜드를 만난다” 증명 + “나도 협찬받고 싶다” 자극.

트렌드·매거진

🔁 크로스미디어

📢 소액 광고

올인원 자동화 시스템

① 기획

업로드할 최적의 주제·아이템을 AI가 선정.

② 수집

트렌드 분석용 데이터를 시스템이 자동 수집.

③ 제작

카드뉴스 이미지 + 본문 캡션까지 AI·시스템이 자동 생성.
